# Dark Green Hacker

Un tema oscuro para VS Code, creado para trabajar con un fondo casi negro y una interfaz inspirada en terminales hacker. Los textos del explorador, la barra superior y la terminal usan tonos verdes, mientras que el resaltado del código conserva colores cercanos al tema nativo de VS Code.

Las clases y los tipos se muestran en verde brillante para que sea fácil ubicarlos mientras programas.

## Instalación

1. Abre la sección **Extensions** en VS Code.
2. Pulsa el menú de tres puntos y selecciona **Install from VSIX...**.
3. Elige `dark-green-vscode-theme-1.0.0.vsix`.
4. Abre `Preferences: Color Theme` y selecciona **Dark Green Hacker**.
